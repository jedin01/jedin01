About

Hi, I'm Abner.

I'm a backend software engineer in Luanda, Angola. At Selenium Digital Solutions I build the automated processes behind Angolan banks on Camunda 8: customer onboarding, integrations with core banking and middleware, and a dormant-account batch that runs end to end with no manual steps.

{% include mascot.html %}

The longer version

Curious about what runs behind the scenes.

I enjoy the parts most people skip. I built a rate limiting layer for a self-managed Zeebe Gateway, I run Keycloak and Docker in our environments, and I read the engine documentation until the why makes sense, not only the how. I share what I learn in my newsletter, Inside the History: Camunda.

Before this I shipped PHP, Laravel and Next.js systems for public sector and education projects, led junior developers through code review, and taught data modeling and programming logic at ITEL. Teaching made me write code that someone else can pick up on a Monday morning.

Outside work I build things for the city I live in: a study platform for Angolan students, a map of Luanda's informal taxi routes, a concept for transparent public procurement.
