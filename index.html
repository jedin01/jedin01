About me

Curious about what runs behind the scenes.

I enjoy the parts most people skip: a rate limiting layer for a self-managed Zeebe Gateway, the default BPMN linting Miragon shipped in their VS Code modeler, Keycloak and Docker in our own environments. I read the engine docs until the why makes sense, then share it in my newsletter.

Before Camunda I shipped PHP, Laravel and Next.js systems, led junior developers through code review and taught data modeling at ITEL. Outside work I build for Luanda: a study platform for students and a map of the city's informal taxi routes.

How I think

Every step modeled, every step running.

A credit request arrives and a DMN table scores the risk. Low-risk requests are approved straight in core banking, the rest go to an analyst, and both paths meet again before the customer hears back. I draw that in BPMN 2.0 with the people who own the process, then write the Java workers that make each task run on Zeebe.
